# Home Assistant Satellite Installer

Repository add-on per **Satellite Installer Pro**.

Add-on Home Assistant dedicato alla progettazione, configurazione e puntamento professionale di impianti satellitari.

## Funzioni v0.1.0
- Calcolo azimut, elevazione e skew LNB da coordinate.
- Astra 19.2°E, Hotbird 13°E, Thor 0.8°W, Eutelsat 5°W.
- LNB Single, Twin, Quad, Octo, Quattro, Wideband.
- SCR / Unicable EN50494 e JESS / dCSS EN50607.
- Valutazione numero utenze/tuner.
- Stima parabola minima.
- Supporto iniziale multifeed.
- Transponder di riferimento per il puntamento.
- Interfaccia responsive tramite Home Assistant Ingress.

## Installazione
Aggiungere questa repository agli Add-on Store di Home Assistant:

`https://github.com/EdisonACDC/-home-assistant-satellite-installer`
