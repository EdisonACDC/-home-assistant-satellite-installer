# Satellite Installer Pro

Add-on Home Assistant per progettazione e puntamento di impianti satellitari.

## Funzioni
- Calcolo azimut, elevazione e skew da località/coordinate.
- Più satelliti e più transponder di riferimento.
- Configurazione Amiko X-Finder 3.
- LNB Single/Twin/Quad/Octo, SCR EN50494, JESS/dCSS EN50607, Quattro + multiswitch e Wideband.
- Profili Wideband per il puntamento tramite modalità User sul misuratore quando compatibile.
- Vista multifeed fronte/retro.
- Calcolo distanza LNB centro-centro in millimetri.
- Interfaccia responsive PC/tablet/telefono via Ingress.
