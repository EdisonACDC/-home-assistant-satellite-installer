# Satellite Installer Pro v0.1.0

Add-on Home Assistant per progettazione e puntamento di impianti satellitari.

## Funzioni iniziali
- Calcolo azimut, elevazione e skew da coordinate.
- Astra 19.2E, Hotbird 13E, Thor 0.8W, Eutelsat 5W.
- LNB Single/Twin/Quad/Octo, SCR EN50494, JESS/dCSS EN50607, Quattro + multiswitch, Wideband.
- Numero utenze/tuner e consiglio architettura.
- Stima parabola minima e maggiorazione base per multifeed.
- Transponder di riferimento per puntamento.
- Interfaccia responsive PC/tablet/telefono via Ingress.
